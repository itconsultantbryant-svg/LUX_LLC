## Live release blockers (not simulated away)

1. Contract-supported Orange business disbursement, verification, currency exponents, limits, status/report semantics and reversal policy.
2. Approved commercial fee incidence and actual fee-collection/allocation workflow. UNCONFIGURED is never authorization-ready.
3. Approved organizations/contracts, authoritative insurer coverage and tariff data, verified destinations and staff identities/MFA.
4. Real storage/scanner, mail sender, backup/restore, privacy/retention and incident operations.
5. Complete remaining operator/task controls, manual accessibility review, production ingress tests and security review.

The safe outcome while these are unresolved is an explicit unavailable/pending state, not a fabricated success.
